Recommended ERP Logic

Do not show every field at once. Each selection should narrow the next dropdown.

  1. Property → choose Specific Unit or Common Area.
  2. Action → Installation, Removal, Installation and Removal, or Repair.
  3. Maintenance Category → AC, Electrical, Plumbing, and so on.
  4. Asset / Item → only items relevant to that category.
  5. Subtype → e.g. Split AC, Window AC, Ducted Split.
  6. Component → e.g. complete unit, compressor, fan motor, thermostat.
  7. Technical Specs → only specifications relevant to the selected asset.
  8. Procurement → create RFQ / purchase requirement only when needed.
Example: Property → Shop 2 → Installation and Removal → Air Conditioning → AC Unit → Split Type → Complete Unit → Carrier → 2 Ton → Qty 1 → Material + Installation.
Action-specific behavior
Installation
Show new asset specifications, unit/common area, quantity and brand.
Removal
Show existing asset details and disposal / storage destination.
Installation and Removal
Show both the existing asset being removed and the new asset specification to be installed.
Repair
Show component/part and fault reason; procurement optional.
